## Animas: Ember v0.0.1: the overworld foundation

First pre-alpha release. Walk around a small town, enter a house through a door warp, talk to NPCs and signs, and wander into tall grass.

**Highlights**
- Grid movement with tap-to-turn / hold-to-walk and tile collision
- Door warps with fade transitions
- Typewriter dialogue, NPCs, and signs, in the new hand-drawn *Animas Pixel* font
- On-screen touch controls on phones and tablets
- Original 16x16 tileset with collision pre-configured
- Playable in the browser: https://pixel-pulse-games.github.io/animas-ember/

**Downloads:** Windows (x86_64, x86_32, arm64), Linux (x86_64, x86_32, arm64, arm32), macOS (universal), and Android (arm64, arm32, x86_64, x86, universal). iOS is available as an Xcode project when enabled.

**Run it in Godot:** install Godot 4.3+, clone the repo, import `project.godot`, press F5.

Full details in the [CHANGELOG](https://github.com/pixel-pulse-games/animas-ember/blob/main/CHANGELOG.md).
