## Pixel Pulse RPG v0.0.1: the overworld foundation

First pre-alpha release. Walk around a small town, enter a house through a door warp, talk to NPCs and signs, and wander into tall grass.

**Highlights**
- Grid movement with tap-to-turn / hold-to-walk and tile collision
- Door warps with fade transitions
- Typewriter dialogue, NPCs, and signs
- Original 16x16 tileset with collision pre-configured
- Playable in the browser: https://pixel-pulse-games.github.io/pixel-pulse-rpg/

**Run it in Godot:** install Godot 4.3+, clone the repo, import `project.godot`, press F5.

Full details in the [CHANGELOG](https://github.com/pixel-pulse-games/pixel-pulse-rpg/blob/main/CHANGELOG.md).
