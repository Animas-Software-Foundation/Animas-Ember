# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-11-15

Phase 2: the animas arrive.

### Added
- **151 original animas** (`AnimaRoster`): 71 evolution families, 12 types, base stats, evolution levels, and dex entries. Every anima has its own generated sprite (`tools/generate_animas.py`, `tools/anima_art.py`)
- **Animadex** screen (Esc, or the DEX button on touch screens) to browse all 151 animas, with Stats and Info pages
- **Wild encounters** in tall grass using per-map encounter tables, with an encounter screen, and `GameState.seen` tracking
- **Trainers with line of sight** (`Trainer`): they spot you, exclaim, walk up, and challenge you, and remember when you have beaten them. Battles themselves arrive later; challenges count as wins for now
- **31 unique character looks** (`CharacterSprite`, `CharacterRoster`, `tools/generate_characters.py`): the hero, rival, villagers, and trainers each have their own skin, hair, outfit, and accessory, with 12 animation frames each
- **Route 1**, a new map east of the town, with three trainers and wild grass
- Website: an interactive gallery of all 151 animas, a character showcase, and a demo with Route 1, trainers, and wild animas (`docs/data.js` is generated by `tools/build_site_data.py`)
- Smoke test coverage for the roster, Animadex, wild encounters, and a full trainer challenge
- **Portable install:** a small Rust launcher (`installer/`, `animas-launch`) points Godot's user data at a `data` folder next to the game, so nothing is written to AppData or the home folder. PC file logging is turned off
- **Self-extracting installer** (`animas-sfx`, written in Rust, about 500 KB): finds the zip payload appended to itself, extracts it to a chosen folder, keeps the `data` folder on updates, rejects unsafe paths, and can launch the game (`--dir`, `--yes`, `--run`, `--list`)
- `tools/package_portable.py` builds the portable archive and the installer for each desktop platform, and `tools/test_installer.py` tests the stub, launcher, and packer (updates, corruption, zip-slip)
- CI now also builds a `-portable` archive and a `-setup` installer for every desktop platform (cross-compiled with cargo-zigbuild)

### Changed
- Player and NPCs now use character sprites instead of the placeholder figures
- The town gained an east exit, new NPCs, and wild grass encounters

### Removed
- `PlaceholderSprite`, replaced by `CharacterSprite`

## [0.0.1] - 2026-11-13

First tagged release: the overworld foundation.

### Changed
- Project renamed to **Animas: Ember**

### Added
- Project website in `docs/` (landing page, playable browser demo using the game's own font, live download links) deployed to GitHub Pages by `pages.yml`
- `tools/render_screenshot.py`, which renders the README and social-card screenshot from the game's own assets
- *Animas Pixel*, a custom bitmap font drawn from scratch (`tools/generate_font.py`), used for all in-game text
- On-screen touch controls for phones and tablets, and a project icon
- Export presets for Windows (x86_64, x86_32, arm64), Linux (x86_64, x86_32, arm64, arm32), macOS (universal), Android (arm64, arm32, x86_64, x86, universal), and iOS
- GitHub Actions workflow (`build.yml`) that tests, builds every platform, and publishes releases on version tags
- Grid-based player movement (tap to turn, hold to walk) with tile collision via `RayCast2D`
- `Warp` markers and a fade `SceneTransition` for moving between maps
- Talkable `NPC` nodes and a typewriter `Dialogue` box (including sign triggers)
- `GameState` autoload with input locking, spawn points, and story flags
- Original 16x16 tileset (`tiles.png` / `tiles.tres`) with collision and a `tall_grass` custom data flag
- Playable starter town and house, built at runtime from ASCII layouts (`AsciiMap`)
- Placeholder character art so the game runs before real sprites exist
- Placeholder tall-grass encounter message
- Headless smoke test (`tools/smoke_test.gd`) and tileset generator (`tools/generate_tiles.py`)
- Browser demo (`docs/index.html`) for GitHub Pages
- Developer documentation in `docs/DEVELOPING.md`
